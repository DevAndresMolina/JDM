# Proyecto Editor JDM Actualizado

Este proyecto permite:

- Editar textos en tiempo real con JavaScript.
- Cambiar colores del nombre, texto superior e inferior.
- Restaurar la selección de iconos:
  - JDM principal rojo
  - JDM con mapa
  - Sin icono
- Aplicar las líneas del mapa del Departamento de Amazonas dentro del nombre principal.
- Descargar el resultado como PNG.

## Estructura

- `index.html`
- `css/styles.css`
- `js/app.js`
- `assets/jdm-principal.png`
- `assets/jdm-mapa.png`
- `assets/amazonas-lineas.png`

## Uso

Abrir `index.html` directamente en el navegador.
No requiere instalación adicional.
